Lab tasks and assignments from my Mobile App Development course, built in Android Studio with Java and XML. Each lab is kept in its own folder and is a standalone Android Studio project.

## Projects

| Folder | Description |
|---|---|
| [Lists](./Lists) | Android app comparing ListView and RecyclerView in Java, showcasing 20 flagship smartphones with Material 3 styling and brand logos. |
| [MyApplication](./MyApplication) | Login and signup app with navigation between screens using explicit and implicit intents. |

## Tech Stack

- Java
- XML layouts
- Android Studio
- Material 3
- ListView and RecyclerView
- Explicit and implicit intents

## Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/furqanzubair209-cell/mobile-app-development-coursework.git
```
2. Open the folder you want in Android Studio.
3. Let Gradle sync, then run the app on an emulator or a physical device (Android 7.0 / API 24 or higher).
